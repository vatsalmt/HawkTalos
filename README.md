# 🦅 HawkTalos — Open Source Cybersecurity Awareness Toolkit

**HawkTalos** is an open-source intelligent application designed to help users improve their cybersecurity posture through interactive tools, real-time threat intelligence, and educational modules. Built with **Python** and a modern web GUI, HawkTalos integrates multiple APIs to provide actionable insights on password strength, email breaches, URL safety, and known exploited vulnerabilities.  

---

## ⚡ Features

- **Password Strength & Breach Checker**  
  Check if your password has been compromised using the **Pwned Passwords API** with k-anonymity.  

- **Email Breach Lookup**  
  Search for known breaches associated with your email using the **Have I Been Pwned API**.  

- **URL Safety Scanner**  
  Scan URLs for phishing or malware using **Google Safe Browsing** and **PhishTank**.  

- **CISA KEV Dashboard**  
  View the latest Known Exploited Vulnerabilities from **CISA**.  

- **Cybersecurity News Feed**  
  Stay updated with curated cybersecurity headlines via [**NewsAPI.org**](https://newsapi.org/).  

- **Learn Module**  
  Bite-sized lessons on **password hygiene**, **phishing detection**, and **MFA best practices**.  

---

## 🛠️ Tech Stack

- **Frontend:** HTML5, CSS3  
- **Backend:** Python  
- **APIs Used:**  
  - Have I Been Pwned (email & password)  
  - Google Safe Browsing  
  - PhishTank  
  - CISA KEV Catalog  
  - NewsAPI
